A program that writes one image summing up the world's news of Tuesday 24 November 2026.

Built for the [make.fun bounty "Sum up 24 November's world news in one image"](https://make.fun/bounty/news-image-20261124). The program writes a 1024x1024 front-page image of the day's news, deterministically, with no network.

Run: `python3 main.py`
